## What it is

**R53 Coding** is an Android app for reading and writing Mini R53 module coding the way you'd do it in **NCS Expert** — without the Windows laptop, INPA install, and daten-file hunt.

Plug a standard **K+DCAN** cable into the OBD port, put a **USB-A to USB-C host (OTG)** adapter on the phone, and the app talks to the modules directly. Definitions ship in the app — no files to import.

I've been testing it on **my two cars**. It works there. What I still need is coverage on an **older R53** — someone who already knows NCS Expert, can take a proper backup first, and is willing to compare what the app reads/writes against a known-good desktop coding session.

## How a coding session works

Key **ON**, engine **OFF**. The live screen is short on purpose:

1. **Select a module** — e.g. Body computer (BC1)
2. **Read from car** — pulls the live coding indexes
3. **Edit options** — full-screen list of settings
4. **Write to car** — commits the change

Before any write, the app saves a **backup**. You can **restore** that backup or **share** it off the phone. A comms log at the bottom shows the TX/RX traffic if something goes sideways.

## Planning mode

You don't need the car plugged in to explore what's available. **Planning mode** opens the same option lists offline — nothing on that screen talks to the car.

![Planning mode — browse coding options offline](/assets/images/r53-coding/planning-mode.jpg){:.img-md}
*Planning mode on BC1.C07 — 273 settings, 76 everyday, the rest under Advanced. Plain titles plus the NCS parameter names.*

Modules show up as tabs (Body computer, Convertible top / CVM, and so on). Each setting card has:

- A **plain-English title**
- The **NCS-style parameter name** (e.g. `TAGFAHRLICHT_ECE`)
- A short **description** where I've been able to write one
- The actual **options** (Off / On, variants, etc.)

I've filled in the common R53 stuff first — country variant, European vs NAS DRL / dipped-beam / fog behaviour, and the other everyday BC1 items people actually change. Advanced stays available for the long tail.

## Hardware

| Piece | Notes |
|-------|-------|
| **K+DCAN cable** | Standard BMW/Mini USB K+DCAN interface |
| **USB-A → USB-C host / OTG** | Phone needs to be the USB host |
| **Android phone** | USB-C host capable |

Same cable family a lot of people already own for INPA / NCS / Tool32 — you're just pointing it at a phone instead of a laptop.

## Fine print

- **Track / DIY use.** You're writing module configuration on a 20-year-old car.
- **Backup first** — with this app *and*, until it's proven on more hardware, with NCS Expert if you have it.
- **Key on, engine off** for live read/write. Don't code with the engine running.
